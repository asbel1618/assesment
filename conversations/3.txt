     COUNTRIES: tuple[str, ...]          # moved from generator, same order

     columns
     def clean_orders(raw: pd.DataFrame) -> tuple[pd.DataFrame, pd.DataFrame]
     - Input: all-string DataFrame with RAW_COLUMNS (loader reads with
       dtype=str, keep_default_na=False — note in docstring). Missing column →
       ValueError. Input not mutated (work on a copy).
     - Pipeline (vectorized where natural, small per-value parsers via .map
       where clearer):
       a. Normalize text: strip + collapse internal whitespace on all columns.
       b. Dedupe: key = normalized values, case-folded for country/status;
          duplicated(keep="first") → rejects, reason duplicate.
       c. Date → datetime.date; accepted formats exactly: YYYY-MM-DD,
          DD/MM/YYYY, Mon DD, YYYY. Month abbreviations via explicit map (no
          locale-dependent %b); calendar validity via datetime.date(...)
          constructor. Anything else (2025-13-45, 2025/02/30, 2O25-03-01, n/a,
          31/02/2025, 2025-00-10, empty) → invalid_date.
       d. Amount → Decimal quantized to 0.01 (NUMERIC(12,2), no float): empty /
          N/A (case-insensitive) → missing_amount; strip leading $, remove ,
          only when it matches thousands grouping
          ^\$?\d{1,3}(,\d{3})*(\.\d{1,2})?$ or plain ^\d+(\.\d{1,2})?$;
          otherwise (abc, -5.00, 1,2,3, 12.345) → invalid_amount.
       e. Country: case-insensitive lookup → canonical name (" SPAIN "→Spain,
          uk→UK); unknown → invalid_country.
       f. Status: lowercase; not in VALID_STATUSES → invalid_status (COMPLETED?,
          shipped).
       g. customer/product empty → missing_customer / missing_product.
     - Output:
       - clean_df: CLEAN_COLUMNS, fresh RangeIndex, original order preserved.
       - rejects_df: original raw (un-normalized) values for RAW_COLUMNS +
         reason; reason order deterministic (date, amount, country, status,
         customer, product).
       - Invariant: len(clean) + len(rejects) == len(raw).
